## What is Modux?

Modux is a **spec-driven code generation framework** for Domain-Driven Design systems. You describe your domain using YAML files and Modux generates a fully structured Spring Boot application following hexagonal architecture — with domain, application, infrastructure, and UI layers — so your team can focus on business logic instead of boilerplate.

## Key features

<CardGrid>
  <Card title="DDD out of the box" icon="puzzle">
    Define aggregates, entities, value objects, domain events, and invariants using a simple YAML DSL.
  </Card>
  <Card title="Full code generation" icon="rocket">
    Generates use cases, repositories, JPA entities, CRUD UI, and database migrations automatically.
  </Card>
  <Card title="Modern patterns" icon="setting">
    CQRS, Event Sourcing, Sagas, Projections, Outbox Pattern, and more — all configurable per aggregate.
  </Card>
  <Card title="Production ready" icon="approve-check">
    Generated projects include Spring Boot 4, Kafka, PostgreSQL, Flyway/Liquibase, and observability support.
  </Card>
