This page lists every file Modux generates and what it contains.

## Project level

| File | Description |
|---|---|
| `pom.xml` | Root Maven POM with multi-module structure |
| `{Service}Application.java` | Spring Boot main class |
| `application.yaml` | Base Spring Boot configuration |
| `application-{env}.yaml` | Per-environment overrides |

## Per aggregate

### Domain layer

| File | Description |
|---|---|
| `domain/aggregates/{aggregate}/{Aggregate}.java` | Aggregate root class |
| `domain/aggregates/{aggregate}/vo/{Aggregate}Id.java` | Strongly-typed aggregate ID |
| `domain/aggregates/{aggregate}/vo/{Aggregate}Name.java` | Typed name wrapper (if `name` field exists) |
| `domain/aggregates/{aggregate}/vo/{Field}.java` | One per `ValueObject`-typed field |
| `domain/aggregates/{aggregate}/events/{Event}.java` | One per domain event |

### Application layer — write side

| File | Description |
|---|---|
| `application/usecases/Create{Aggregate}UseCase.java` | Create use case interface |
| `application/usecases/Create{Aggregate}Command.java` | Create command DTO |
| `application/usecases/Update{Aggregate}UseCase.java` | Update use case interface |
| `application/usecases/Update{Aggregate}Command.java` | Update command DTO |
| `application/usecases/Delete{Aggregate}UseCase.java` | Delete use case interface |
| `application/usecases/{Operation}UseCase.java` | One per custom operation |
| `application/usecases/{Operation}Command.java` | Command DTO per custom operation |
| `application/out/{Aggregate}Repository.java` | Repository port interface |

### Application layer — read side

| File | Description |
|---|---|
| `application/query/{Aggregate}QueryService.java` | Query service interface |
| `application/query/{Aggregate}Dto.java` | Full detail DTO |
| `application/query/{Aggregate}Row.java` | List row DTO |

### Infrastructure — persistence

| File | Description |
|---|---|
| `infra/out/persistence/{Aggregate}Entity.java` | JPA entity |
| `infra/out/persistence/{Aggregate}EntityRepository.java` | Spring Data JPA repository |
| `infra/out/persistence/{Aggregate}DBRepository.java` | Repository port implementation |
| `infra/out/persistence/{Aggregate}DBQueryService.java` | Query service implementation |

### Infrastructure — UI

| File | Description |
|---|---|
| `infra/in/ui/{Aggregate}CrudAdapter.java` | Wires UI to use cases and query service |
| `infra/in/ui/{Aggregate}CrudOrchestrator.java` | Manages UI view state and navigation |
| `infra/in/ui/{Aggregate}ViewModel.java` | UI binding model |
| `infra/in/ui/{Aggregate}IdOptionsSupplier.java` | Provides dropdown options for foreign key fields |
| `infra/in/ui/{Aggregate}IdLabelSupplier.java` | Provides display labels for aggregate IDs |

## Per projection & read model

| File | Description |
|---|---|
| `infra/in/projection/{Projection}Projection.java` | Event handler that maintains the read model |
| `application/query/readmodel/{ReadModel}ReadModel.java` | Read-side DTO |
| `infra/out/persistence/{ReadModel}ReadModelEntity.java` | Read model JPA entity |
| `infra/out/persistence/{ReadModel}ReadModelEntityRepository.java` | Spring Data repository |
| `application/query/{ReadModel}ReadModelQueryService.java` | Read model query service (+ DB implementation) |

## Per gateway

| File | Description |
|---|---|
| `application/out/{Gateway}Gateway.java` | Gateway port interface; typed method per operation |
| `infra/out/gateway/{Gateway}GatewayImpl.java` | `RestTemplate` adapter (body, auth, parameter binding, typed response) |
| `application/out/gateway/dto/{Model}.java` | Typed record per request/response model |

## Per scheduled trigger

| File | Description |
|---|---|

## DevOps & infrastructure

| File | Description |
|---|---|
| `docker-compose.yml` | Project root; one entry per service plus Postgres and Kafka |
| `.github/workflows/ci.yml` | Project root; builds and tests each service |
| `terraform/main.tf` | Project root; Terraform skeleton |
| `{service}/Dockerfile` | Multi-stage image per service |
| `{service}/k8s/{service}.yaml` | Kubernetes Deployment + Service + optional HPA |

These are skipped when generating with `sourceOnly` (see the [Maven Plugin Reference](/reference/maven-plugin/)). The generated service POMs also include JaCoCo, Spotless and the Maven Enforcer plugin.

---

## Code formatting

All generated Java files are formatted using **Google Java Format** before being written to disk. This ensures consistent style regardless of field order or template output.
